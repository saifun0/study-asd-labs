## Теоретическое обоснование
Перегрузка операторов позволяет определить естественное математическое поведение стандартных знаков операций (`+`, `-`, `*`, `/`, `==`, `<<` и др.) для объектов создаваемых классов.

Способы перегрузки операторов в C++:
1. **Как метод класса:** неявным первым аргументом всегда выступает текущий объект `*this`. Метод подходит для унарных операторов (`++`, `--`), оператора присваивания (`=`), индексации (`[]`), функционального вызова (`()`) и составного присваивания (`+=`, `-=`).
2. **Как внешняя дружественная функция (`friend`):** функция не принадлежит классу, но имеет доступ к его закрытым полям (`private`). Этот способ обязателен, когда левый операнд относится к другому типу (например, `std::ostream` в операторах `<<` и `>>`), а также обеспечивает симметричность при бинарных операциях со смешанными типами.

Правила перегрузки инкремента и декремента:
* Префиксная форма (`++z`) возвращает ссылку на уже измененный объект: `Complex& operator++()`.
* Постфиксная форма (`z++`) принимает фиктивный целочисленный параметр `int`, сохраняет старое состояние объекта, увеличивает поле и возвращает прежнюю копию по значению: `Complex operator++(int)`.

Оператор функционального вызова `operator()(int n)` превращает объект в функтор. В данном проекте он используется для возведения комплексного числа в целую степень.

## Пошаговое выполнение работы

### Шаг 1. Объявление класса и интерфейса (`Complex.h`)
Класс хранит действительную часть `double re` и мнимую часть `double im`:

```cpp
#pragma once
#include <iostream>

class Complex {
private:
    double re;
    double im;

public:
    Complex();
    Complex(double re, double im);
    Complex(const Complex& other);
    ~Complex();

    Complex& operator=(const Complex& other);

    double getRe() const;
    double getIm() const;
    void setRe(double re);
    void setIm(double im);

    double abs() const;
    double arg() const;
    double argDegrees() const;

    // Арифметические операторы
    Complex operator+(const Complex& other) const;
    Complex operator-(const Complex& other) const;
    Complex operator*(const Complex& other) const;
    Complex operator/(const Complex& other) const;

    // Составное присваивание
    Complex& operator+=(const Complex& other);
    Complex& operator-=(const Complex& other);
    Complex& operator*=(const Complex& other);
    Complex& operator/=(const Complex& other);

    // Сравнение
    bool operator==(const Complex& other) const;
    bool operator!=(const Complex& other) const;
    bool operator<(const Complex& other) const;
    bool operator>(const Complex& other) const;

    // Инкремент и декремент
    Complex& operator++();
    Complex operator++(int);
    Complex& operator--();
    Complex operator--(int);

    // Функтор (возведение в степень)
    Complex operator()(int n) const;

    // Дружественные операторы ввода-вывода
    friend std::ostream& operator<<(std::ostream& out, const Complex& z);
    friend std::istream& operator>>(std::istream& in, Complex& z);
};
```

### Шаг 2. Реализация арифметических операций (`Complex.cpp`)
Арифметические операции реализуются по формулам комплексного анализа с контролем деления на ноль:

```cpp
Complex Complex::operator*(const Complex& other) const {
    return Complex(re * other.re - im * other.im,
                   re * other.im + im * other.re);
}

Complex Complex::operator/(const Complex& other) const {
    double denom = other.re * other.re + other.im * other.im;
    if (denom == 0.0) {
        throw std::runtime_error("Деление на ноль");
    }
    return Complex((re * other.re + im * other.im) / denom,
                   (im * other.re - re * other.im) / denom);
}
```

### Шаг 3. Инкремент, декремент и функтор
Реализованы дифференцированные сигнатуры префиксного и постфиксного операторов, а также возведение в целую степень через `operator()`:

```cpp
Complex& Complex::operator++() {
    ++re;
    return *this;
}

Complex Complex::operator++(int) {
    Complex old = *this;
    ++re;
    return old;
}

Complex Complex::operator()(int n) const {
    Complex result(1.0, 0.0);
    int count = (n >= 0) ? n : -n;
    for (int i = 0; i < count; ++i) {
        result *= *this;
    }
    if (n < 0) {
        result = Complex(1.0, 0.0) / result;
    }
    return result;
}
```

### Шаг 4. Дружественные операторы ввода-вывода
Операторы потока работают напрямую с закрытыми полями, поддерживая непрерывные цепочки вызовов:

```cpp
std::ostream& operator<<(std::ostream& out, const Complex& z) {
    out << z.re;
    if (z.im >= 0) out << "+";
    out << z.im << "i";
    return out;
}

std::istream& operator>>(std::istream& in, Complex& z) {
    in >> z.re >> z.im;
    return in;
}
```

## Контрольные вопросы

### 1. Что такое перегрузка операторов и для чего она применяется?
Перегрузка операторов позволяет наделить стандартные операции C++ поведением, специфичным для пользовательских типов данных. Это делает работу с объектами классов интуитивно понятной и позволяет записывать сложные вычисления в виде естественных математических выражений.

### 2. Какие операторы в языке C++ нельзя перегружать?
В C++ запрещено перегружать пять операторов: оператор прямого доступа к члену (`.`), оператор доступа к члену по указателю (`.*`), оператор разрешения области видимости (`::`), тернарный условный оператор (`?:`) и оператор вычисления размера `sizeof`.

### 3. В чем разница между перегрузкой оператора методом класса и дружественной функцией?
Оператор-метод получает левый операнд неявно через указатель `this`, поэтому левым операндом может быть только объект этого же класса. Дружественная функция получает оба операнда явно через список параметров, что позволяет левому операнду принадлежать другому типу (например, `std::cout << z`).

### 4. Для каких операторов предпочтительнее использовать дружественные функции?
Дружественные функции предпочтительны для потокового ввода-вывода (`<<`, `>>`), а также для симметричных бинарных арифметических операций (`+`, `*`), когда требуется поддержать операции вида `2.0 + z` наряду с `z + 2.0`.

### 5. Как различаются сигнатуры префиксного и постфиксного инкремента?
Префиксный оператор объявляется без аргументов: `Complex& operator++()`. Постфиксный оператор имеет фиктивный целочисленный параметр `int`, используемый компилятором исключительно для разрешения неоднозначности: `Complex operator++(int)`.

### 6. Почему операторы потокового ввода и вывода нельзя перегрузить как методы класса?
В выражениях `std::cout << z` левым операндом выступает экземпляр `std::ostream`. Если перегружать оператор как метод, его пришлось бы встраивать в класс `std::ostream`, что невозможно без модификации исходного кода стандартной библиотеки C++.

### 7. Что такое дружественная функция?
Дружественная функция объявляется внутри класса с ключевым словом `friend`. Она не является членом класса, но имеет полный доступ ко всем его закрытым (`private`) и защищенным (`protected`) полям и методам.

### 8. Что такое функтор и как перегружается оператор ()?
Функтор представляет собой объект класса, который можно вызывать подобно обычной функции. Это достигается за счет перегрузки оператора вызова функции: `Complex operator()(int n) const`. В отличие от функций, функтор может сохранять и накапливать внутреннее состояние между вызовами.
