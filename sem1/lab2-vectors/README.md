## Теоретическое обоснование
Контейнер `std::vector` представляет собой динамический массив с автоматическим управлением памятью. Элементы вектора хранятся в непрерывной области оперативной памяти, что обеспечивает быстрый доступ по индексу за время $O(1)$ и высокую локальность данных при кешировании.

Основные характеристики вектора:
* Метод `size()` возвращает текущее количество элементов.
* Метод `capacity()` возвращает текущую выделенную емкость буфера памяти.
* Метод `push_back()` добавляет элемент в конец за амортизированное время $O(1)$. Если буфер заполнен, происходит перевыделение памяти с коэффициентом роста (обычно 1.5 или 2.0).

Для навигации по элементам контейнеров используются итераторы: объекты, обобщающие концепцию указателей. Константный итератор `vector<int>::const_iterator` позволяет читать элементы без права их изменения.

Для удаления элементов по предикату применяется связка алгоритма `std::remove_if` и метода контейнера `erase` (идиома *erase-remove*). Алгоритм `remove_if` перемещает элементы, не удовлетворяющие условию, в начало контейнера и возвращает итератор на начало отсекаемой части, а метод `erase` физически укорачивает вектор.

## Пошаговое выполнение работы

### Шаг 1. Реализация ввода и вывода вектора
Функция `input()` запрашивает количество элементов `n`, выделяет вектор нужного размера и заполняет его числами с клавиатуры с валидацией ввода:

```cpp
vector<int> input() {
    int n = readInt("Введите количество элементов n: ");
    while (n < 0) {
        cout << "Ошибка: количество не может быть отрицательным." << endl;
        n = readInt("Введите количество элементов n: ");
    }

    vector<int> v(n);
    if (n > 0) {
        cout << "Введите элементы вектора (" << n << " шт.) через пробел: ";
    }
    for (int i = 0; i < n; ++i) {
        cin >> v[i];
    }
    return v;
}
```

Вывод элементов осуществляется через константный итератор `const_iterator`:

```cpp
void print(const vector<int>& v) {
    if (v.empty()) {
        cout << "(вектор пуст)" << endl;
        return;
    }
    for (vector<int>::const_iterator it = v.begin(); it != v.end(); ++it) {
        cout << *it << " ";
    }
    cout << endl;
}
```

### Шаг 2. Удаление полных квадратов и подсчет суммы (Задание 1)
По условию задания 1 из вектора удаляются все элементы, являющиеся квадратами целых чисел (0, 1, 4, 9, 16, 25...), после чего находится сумма оставшихся:

```cpp
bool isPerfectSquare(int x) {
    if (x < 0) return false;
    long long root = static_cast<long long>(sqrt(static_cast<double>(x)) + 0.5);
    return root * root == x;
}

void task1() {
    vector<int> v = input();
    
    // Идиома erase-remove для отсечения полных квадратов
    v.erase(remove_if(v.begin(), v.end(), isPerfectSquare), v.end());

    cout << "Вектор без полных квадратов: ";
    print(v);

    long long sum = 0;
    for (vector<int>::const_iterator it = v.begin(); it != v.end(); ++it) {
        sum += *it;
    }
    cout << "Сумма оставшихся элементов: " << sum << endl;
}
```

### Шаг 3. Поиск троек с цифрой 3 и простой суммой (Задание 2)
По условию задания 2 анализируются все тройки подряд идущих элементов вектора. Тройка подходит, если каждое из трех чисел содержит цифру 3 в десятичной записи, а сумма чисел тройки является простым числом:

```cpp
bool containsDigit3(int x) {
    long long value = (x < 0) ? -static_cast<long long>(x) : x;
    while (value > 0) {
        if (value % 10 == 3) return true;
        value /= 10;
    }
    return false;
}

bool isPrime(long long x) {
    if (x < 2) return false;
    for (long long d = 2; d * d <= x; ++d) {
        if (x % d == 0) return false;
    }
    return true;
}

void task2() {
    vector<int> v = input();
    int count = 0;
    long long minSum = 0;
    bool found = false;

    for (size_t i = 0; i + 2 < v.size(); ++i) {
        int a = v[i], b = v[i + 1], c = v[i + 2];
        if (containsDigit3(a) && containsDigit3(b) && containsDigit3(c)) {
            long long sum = static_cast<long long>(a) + b + c;
            if (isPrime(sum)) {
                ++count;
                if (!found || sum < minSum) {
                    minSum = sum;
                    found = true;
                }
            }
        }
    }
    cout << "Количество троек: " << count << endl;
    if (found) cout << "Минимальная сумма: " << minSum << endl;
}
```

## Контрольные вопросы

### 1. Какой заголовочный файл требуется подключить для использования вектора?
Для работы с шаблоном `std::vector` подключается заголовочный файл `<vector>`.

### 2. В чем разница между методами size() и capacity()?
Метод `size()` возвращает фактическое количество элементов, хранящихся в векторе в данный момент. Метод `capacity()` возвращает объем памяти (количество ячеек), зарезервированный под элементы без необходимости повторного выделения памяти.

### 3. Как работает идиома erase-remove?
Функция `std::remove_if` не может изменить размер контейнера, поскольку работает только через пару итераторов. Она перезаписывает элементы, удовлетворяющие условию, элементами из правой части диапазона и возвращает итератор на новый логический конец. Метод вектора `v.erase(new_end, v.end())` удаляет оставшийся хвост и корректирует размер контейнера.

### 4. Что такое итератор и какие операции с ним поддерживаются для vector?
Итератор вектора относится к категории итераторов произвольного доступа (*random access iterator*). Он поддерживает разыменование (`*it`), инкремент и декремент (`++`, `--`), сложение и вычитание со смещением (`it + k`), сравнение на равенство и порядок (`<`, `>`, `==`, `!=`), а также оператор индексации `it[k]`.

### 5. Чем отличается обращение к элементам через v[i] и v.at(i)?
Оператор `v[i]` не выполняет проверку выхода за границы вектора ради максимального быстродействия. Метод `v.at(i)` проверяет индекс и в случае выхода за допустимый диапазон выбрасывает исключение `std::out_of_range`.
