## Теоретическое обоснование
В стандартной библиотеке C++ файловый ввод-вывод реализован через иерархию классов заголовочного файла `<fstream>`:
* `ifstream` (унаследован от `istream`) используется для чтения данных из файла.
* `ofstream` (унаследован от `ostream`) используется для записи данных в файл.
* `fstream` (унаследован от `iostream`) поддерживает одновременное чтение и запись.

Текстовые файлы хранят информацию в виде последовательности символов, разделенных символами перевода строки (`\n` или `\r\n`). При чтении чисел из текстового файла строковое представление автоматически преобразуется во внутренний формат переменной оператором `>>`.

Бинарные файлы сохраняют байтовое представление данных прямо из оперативной памяти без текстового форматирования. Для открытия файла в двоичном режиме передается флаг `ios::binary`. Обмен данными выполняется через методы:
* `write(reinterpret_cast<const char*>(&val), sizeof(val))` для записи блока байтов в поток.
* `read(reinterpret_cast<char*>(&val), sizeof(val))` для считывания блока байтов из потока.

При работе с записями фиксированного размера (структурами без динамических полей) бинарный формат сохраняет объект целиком за один вызов метода `write`.

## Пошаговое выполнение работы

### Шаг 1. Обработка текстового файла (Задание 6)
По условию варианта 1 дан файл `f.txt` с действительными числами. Программа выводит содержимое файла, находит произведение всех компонент и записывает результат в файл `result.txt`:

```cpp
void task6() {
    // 1. Чтение чисел из файла и вычисление произведения
    ifstream in(TEXT_FILE);
    vector<double> numbers;
    double x;
    while (in >> x) {
        numbers.push_back(x);
    }
    in.close();

    double product = 1.0;
    for (double val : numbers) {
        product *= val;
    }

    // 2. Сохранение результата в новый файл
    ofstream out(RESULT_FILE);
    out << "Количество чисел: " << numbers.size() << endl;
    out << "Произведение чисел: " << setprecision(15) << product << endl;
    out.close();
}
```

### Шаг 2. Работа с массивом целых чисел в бинарном файле (Задание 9)
Программа принимает массив целых чисел, записывает его в бинарный файл `numbers.bin`, считывает обратно, удваивает каждое значение и перезаписывает файл:

```cpp
bool writeNumbers(const string& name, const vector<int>& numbers) {
    ofstream out(name, ios::binary);
    if (!out.is_open()) return false;
    for (int value : numbers) {
        out.write(reinterpret_cast<const char*>(&value), sizeof(value));
    }
    return true;
}

vector<int> readNumbers(const string& name) {
    vector<int> numbers;
    ifstream in(name, ios::binary);
    int value;
    while (in.read(reinterpret_cast<char*>(&value), sizeof(value))) {
        numbers.push_back(value);
    }
    return numbers;
}
```

bool hasNoTwos(const Student& s) {
    for (int i = 0; i < 3; ++i) {

void task10() {

## Контрольные вопросы

### 1. В чем разница между текстовым и бинарным режимом открытия файла?
В текстовом режиме при чтении и записи происходит автоматическая трансляция символов конца строки (на Windows символ `\n` при записи превращается в пару байтов `\r\n`, а при чтении наоборот). В бинарном режиме (`ios::binary`) трансляция отключена, и байты переносятся между диском и памятью без изменений.

### 2. Какие классы стандартной библиотеки C++ используются для работы с файлами?
Класс `std::ifstream` предназначен для чтения данных, `std::ofstream` для записи данных, а `std::fstream` поддерживает обе операции одновременно. Все три класса определены в заголовке `<fstream>`.

### 3. Как работают методы read() и write()?
Метод `write(const char* s, streamsize n)` копирует `n` байт из буфера памяти по адресу `s` в выходной поток. Метод `read(char* s, streamsize n)` считывает `n` байт из входного потока в буфер `s`. Приведение указателей выполняется с помощью `reinterpret_cast<char*>`.

### 4. Почему в структурах для бинарной записи нельзя использовать std::string или динамические указатели?
Объект `std::string` хранит внутри указатель на динамическую память в куче. Если записать такую структуру через `write`, в файл попадет только адрес памяти, который потеряет смысл после перезапуска программы. Для бинарной сериализации подходят структуры со статическими массивами фиксированной длины (например, `char fio[50]`).

### 5. Для чего служат методы seekg() и seekp()?
Метод `seekg()` перемещает указатель чтения во входном потоке, а метод `seekp()` перемещает указатель записи в выходном потоке. Они принимают смещение в байтах и точку отсчета (`ios::beg`, `ios::cur`, `ios::end`), обеспечивая произвольный доступ к содержимому файла.

### 6. Как проверить корректность открытия файла?
Для этого вызывается метод `is_open()`. Если файл не удалось открыть (например, файл не существует или нет прав доступа), метод вернет `false`.
