# Лабораторные работы по дисциплине «Алгоритмы и структуры данных» (АСД)

Учебный репозиторий с практическими и лабораторными работами по дисциплине «Алгоритмы и структуры данных» на языке C++.

## 🛠 Стек технологий и окружение
- **Язык программирования:** C++ (C++17 / C++20)
- **Среда разработки:** Visual Studio 2022+ (поддержка формата решения `.slnx` и проектов `.vcxproj`)
- **Платформа:** Windows (x64 / x86)

## 📚 Описание лабораторных работ (1 семестр)

### 🔹 Лабораторная работа №1: Файловые потоки ввода-вывода
Работа с текстовыми и бинарными файлами средствами `<fstream>` (Вариант 1, средний уровень):
- **Задание 6 (Текстовые файлы):** Чтение действительных чисел из файла (`f.txt`), вычисление их произведения и сохранение результата в отдельный файл.
- **Задание 9 (Бинарные файлы):** Запись массива целых чисел в бинарный файл, побайтовое чтение и модификация содержимого (удвоение значений).
- **Задание 10 (Файлы структур):** Работа с бинарным файлом структур данных (`struct Student`): запись, чтение, фильтрация по успеваемости (выборка студентов без двоек).

### 🔹 Лабораторная работа №2: Векторы и итераторы
Изучение контейнера `std::vector`, стандартных итераторов и алгоритмов `<algorithm>`:
- **Задание 1:** Обработка и модификация элементов динамического массива с использованием прямых и обратных итераторов.
- **Задание 2:** Фильтрация, удаление элементов по заданным предикатам (идиома *erase-remove*), работа с диапазонами.

### 🔹 Лабораторная работа №3: Классы и объекты. Класс `Date`
Основы объектно-ориентированного программирования, инкапсуляция:
- Класс `Date` для представления календарной даты (день, месяц, год).
- Конструкторы (по умолчанию, с параметрами, копирования), деструктор.
- Методы доступа (геттеры и сеттеры) со строгой валидацией корректности даты с учётом високосных лет (`isLeapYear`, `daysInMonth`).

### 🔹 Лабораторная работа №4: Динамические структуры. Класс `IntVector`
Управление динамической памятью, реализация собственного контейнера целых чисел:
- Класс `IntVector` — аналог динамического массива.
- Реализация **«Правила трёх»** (*Rule of Three*): деструктор, конструктор глубокого копирования и перегруженный оператор присваивания `operator=`.
- Методы управления ёмкостью и размером (`push_back`, `pop_back`, `insert`, `erase`, `reallocate`).
- Перегрузка оператора индексации `operator[]` с контролем выхода за границы массива.

### 🔹 Лабораторная работа №5: Перегрузка операторов. Класс `Complex`
Математические абстракции и расширенная перегрузка операторов в C++:
- Класс `Complex` для представления комплексных чисел ($a + bi$).
- Перегрузка арифметических операторов: сложение (`+`), вычитание (`-`), умножение (`*`), деление (`/`) и составное присваивание (`+=`, `-=`, `*=`, `/=`).
- Перегрузка операций сравнения (`==`, `!=`).
- Перегрузка операторов потокового ввода/вывода в консоль (`operator<<`, `operator>>`).
- Вычисление модуля (`abs`) и аргумента комплексного числа в радианах и градусах (`arg`, `argDegrees`).

## 🚀 Запуск и сборка

### Открытие в Visual Studio:
1. Запустите Visual Studio 2022 или новее.
2. Откройте файл решения [`study-asd-labs.slnx`](./study-asd-labs.slnx).
3. В Обозревателе решений выберите нужный проект (например, `sem1-lab3-date`), нажмите по нему правой кнопкой мыши и выберите **«Назначить запускаемым проектом»** (*Set as Startup Project*).
4. Запустите проект клавишей `F5` (с отладкой) или `Ctrl + F5` (без отладки).
