# Лабораторные по алгоритмам и структурам данных (АСД)

Репозиторий с лабораторными работами за 1 семестр. Проекты написаны на C++ и собраны в решение для Visual Studio 2022 (формат .slnx).

## Структура

В папке sem1 лежат пять лабораторных работ (вариант 1, средний уровень):

* lab1-files (файловые потоки)
  Работа с текстовыми и бинарными файлами через fstream. Считает произведение вещественных чисел из f.txt (задание 6), удваивает целые числа в бинарном файле (задание 9) и фильтрует список студентов из файла по оценкам, убирая двойки (задание 10).

* lab2-vectors (векторы и итераторы)
  Примеры работы с std::vector и стандартными итераторами. Включает изменение элементов по условию и удаление значений через предикаты и remove_if.

* lab3-date (класс даты)
  Класс Date для работы с датами (день, месяц, год). Написаны конструкторы, проверка корректности с учетом високосных лет и расчет високосного года.

* lab4-intvector (собственный динамический массив)
  Аналог вектора для целых чисел IntVector. Реализовано правило трех (деструктор, конструктор копирования, оператор присваивания), методы push_back, pop_back, insert, erase и обращение по индексу [] с проверкой выхода за границы.

* lab5-complex (комплексные числа)
  Класс Complex для чисел вида a + bi. Перегружены арифметические операторы (+, -, *, /), составные присваивания, сравнение и ввод-вывод через >> и <<. Также добавлены методы вычисления модуля и аргумента числа.

## Как запустить

Проект проще всего открыть в Visual Studio:

1. Открыть файл study-asd-labs.slnx.
2. В Обозревателе решений кликнуть правой кнопкой по нужной лабораторной (например, sem1-lab3-date) и выбрать "Назначить запускаемым проектом".
3. Нажать Ctrl + F5 для запуска.
